# План: фильтры и быстрое копирование во вкладке «Связь»

> **Сделано в 0.8.3.** Итоговые решения — в разделе «Что решили» в конце; описание — `docs/releases/v0.8.3.md`.

Запрос друга (05.11.2026):

- фильтр списка во вкладке «Связь»: UDP или TCP;
- обращение по доменному имени или напрямую по адресу;
- быстрые кнопки копирования домена и адреса — без правой кнопки и лишних кликов.

## Что есть сейчас (v0.8.2)

- Список серверов программы — `ListBox x:Name="ServerList"` в `src/NetWatcher.App/Views/MainWindow.xaml`,
  данные — `LinkServers` из `ApplyProgram` в `src/NetWatcher.App/ViewModels/MainViewModel.Link.cs`.
  У каждой строки есть `LinkServerView.Row` — обычная `DestinationRow` (протокол, IP, порт, домены).
- Быстрые фильтры (`TCP`, `UDP`, «С доменом», «Без домена», «Проблемные», «Трекеры»…) и поиск видны над всеми
  вкладками, но **на «Связь» не действуют**: `ApplyProgram` берёт все `p.Servers` без фильтра. Это путает.
- Копирование — только в меню строки (`ServerMenu`): «Копировать адрес» копирует `IP:порт`,
  «Копировать имя сервера» — домен.

## Решение

### 1. Фильтры: общие быстрые фильтры и поиск начинают действовать на «Связь»

Новых переключателей не добавляем: используем те, что уже есть над вкладками. Так фильтр один на всю программу
и не спорит сам с собой.

- В `ApplyProgram` список серверов фильтруется теми же правилами, что таблица:
  `QuickFilters.Pass(server.Row, Filters)` и `server.Row.Matches(words)` (оба уже в `NetWatcher.Core`).
  - `TCP` / `UDP` — протокол сервера; оба сразу — «любой».
  - «С доменом» — программа обратилась по имени (известен ответ DNS); «Без домена» — напрямую по IP.
  - Остальные фильтры («Проблемные», «Трекеры», «Телеметрия», «Только IPv4»…) работают так же, как в таблице.
- Над списком серверов — строка «Показано 5 из 12 серверов · Сбросить», когда фильтр или поиск включены.
- Обзор «Все программы» (карточки): при включённом фильтре показываются только программы, у которых есть
  подходящие серверы. Состояние карточки по-прежнему считается по всем серверам программы.
- Важно честно подписать «Без домена»: домен может быть неизвестен и при обращении по имени — если программа
  спрашивает DNS сама (DNS через HTTPS) или узнала адрес до запуска NetWatcher. Подсказка у фильтра это говорит.

### 2. Быстрое копирование

- В каждой строке сервера, при наведении и у выбранной строки, — две кнопки, как в таблице «Все адреса»:
  - «Копировать домен» — домен сервера; кнопки нет, если домен неизвестен;
  - «Копировать IP» — только IP, без порта.
- В заголовке списка — «Копировать все домены (N)» и «Копировать все IP (N)»: уникальные значения видимых
  (отфильтрованных) серверов, по одному в строке — удобно для списков VPN и правил.
- Меню строки: пункты переименовать в «Копировать домен», «Копировать IP», «Копировать IP:порт».
- Клавиши — как в таблице: `Ctrl+C` — строка целиком («домен IP:порт протокол»), `Ctrl+Shift+C` — только IP.
- После копирования — то же всплывающее «Скопировано: … · Отменить», что в таблице.

### 3. Затронутые файлы

| Файл | Что меняется |
|---|---|
| `ViewModels/MainViewModel.Link.cs` | фильтр серверов и карточек, счётчик «Показано N из M», команды копирования |
| `ViewModels/MainViewModel.cs` | изменение фильтров и поиска обновляет и вкладку «Связь» (сейчас — только таблицу) |
| `Views/MainWindow.xaml` | кнопки в строке сервера, заголовок списка с «Копировать все…», новые подписи меню |
| `Views/MainWindow.xaml.cs` | `Ctrl+C` / `Ctrl+Shift+C` для выбранного сервера |
| `tests/NetWatcher.Core.Tests` | фильтр серверов: TCP/UDP, с доменом / без домена, поиск по домену и IP |
| `tests/NetWatcher.App.Tests` | команды копирования привязаны и копируют IP без порта (как `UpdateBindingTests`) |
| `README.md`, `docs/releases/v0.8.3.md` | описание; версия 0.8.3 в `Directory.Build.props` |

### 4. Проверка

1. Выбрать программу с TCP и UDP (Telegram, игра) → `UDP` → в списке только UDP, «Показано N из M».
2. «Без домена» → только серверы без известного имени; «С доменом» → только с именем.
3. Поиск `149.154` или части домена → список сужается так же, как таблица.
4. Навести на строку → «Копировать IP» → в буфере IP без порта; «Копировать домен» → только домен.
5. «Копировать все IP» при включённом `UDP` → только IP видимых UDP-серверов.
6. Список обновляется каждые 2 с: фильтр и выделение не сбрасываются, меню не закрывается (как в 0.8.1).

Оценка: около полудня работы, без новых зависимостей.

## Открытые вопросы

1. Общие фильтры (рекомендуется) или отдельная панель фильтров прямо в списке серверов.
2. «Копировать IP» — без порта (рекомендуется; с портом остаётся в меню) или с портом.
3. Фильтровать ли карточки обзора «Все программы» или только список серверов выбранной программы.

по щелчку; убрать повторы из меню; узкая полоса графика. Быстрые фильтры сверху тоже работают на «Связь» —
выставляют фильтры столбцов.

- Фильтры по столбцам: `src/NetWatcher.Core/Link/ServerFilter.cs` (тесты — `ServerFilterTests`), строка фильтров

  «Без домена» ↔ способ обращения, «Проблемные» ↔ состояние; «Трекеры», «Телеметрия», «Только новые»,
