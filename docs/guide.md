# Руководство NetWatcher

[К описанию проекта](../README.md)

## Что можно сделать

### Найти программу и её адреса

Слева — «Приложения» и «Службы Windows». Службы внутри `svchost.exe` показаны по именам:
например, «Центр обновления Windows» вместо общего `svchost`. У каждой программы видны объём трафика за период
или число адресов, график трафика за 7 часов и значок связи. Текст статуса — в подсказке.
Метка **НОВОЕ** означает, что программа впервые замечена в журнале за последние сутки.
Список можно упорядочить по активности, имени или трафику.

Выберите, как смотреть соединения:

- «По доменам» — адреса собраны под доменами, программа → домен → адреса.
- «Все адреса» — общий список с сортировкой по колонкам.
- «Журнал DNS» — имена, которые запрашивала программа, и адреса в ответах.

Поиск работает сразу по программе, службе, IP, порту, домену, владельцу и стране.
Подсеть `142.250.0.0/15` находит адреса внутри неё. Одним нажатием можно включить фильтры
TCP, UDP, «С доменом», «Без домена», «Проблемные», «Только новые», «Трекеры», «Телеметрия»,
«Скрыть Microsoft» и «Только IPv4». Счётчик показывает результат, например «Найдено 7 из 64».
Нажмите `Esc`, чтобы сбросить поиск и фильтры.

Переключатель периода даёт выбор: сейчас, 15 минут, час, сутки, неделя или всё.
Срок хранения журнала задаётся в настройках — по умолчанию 7 дней.

### Узнать, с кем связывается программа

Выберите адрес: под таблицей появятся IP, домены, сеть владельца (`/24` или маска), владелец,
страна, протокол, время первого и последнего обращения. У каждого поля есть кнопка копирования.
«Подробно о сети (RDAP)» запрашивает данные регистратора. Без выделенной строки здесь показана
сводка программы. Перетащите разделители, чтобы изменить ширину списка программ и высоту
сведений: NetWatcher запомнит размеры.

Названия из реестра очищены от служебных частей. У известных сетей — привычные имена:
`AS8075 · Microsoft` вместо `MICROSOFT-CORP-MSN-AS-BLOCK`.
Полное название из реестра можно прочитать в подсказке. Кнопка «Владелец (PeeringDB)» уточняет
название и тип сети в открытом справочнике PeeringDB: провайдер, CDN, магистральный оператор
и другие. Ответ сохраняется для следующих обращений.

Страна сервера определяется по IP из базы DB-IP; возможны ошибки. Она может отличаться
от страны регистрации сети, в том числе у Cloudflare, Google и Amazon. Страна регистрации — в подсказке.

Рядом с доменом могут быть пометки «трекер», «телеметрия» или «опасный», а в карточке —
компания-владелец. Источники — списки DuckDuckGo и WindowsSpyBlocker, см. «Откуда берутся данные».
Для поиска таких доменов есть фильтры «Трекеры» и «Телеметрия».

В карточке адреса и сводке программы есть пояснения: что это за программа, служба Windows
или домен, зачем использует сеть и к чему может привести блокировка. Последствия зависят
от выбранного правила. В каталоге около 100 описаний распространённых служб, программ и доменов.
Если записи нет, пояснение не показывается.

### Посмотреть трафик и получать уведомления

В колонке «Объём» виден трафик каждого адреса. В сводке — сколько данных получено и отправлено
за период и средняя скорость за последние 10 секунд. NetWatcher считает полезные данные
без заголовков пакетов. За период до часа учёт точный, за сутки и больше — с точностью до часа:
журнал хранит итоги по часам.

В сводке нажмите «Трафик за 30 дней по данным Windows…», чтобы посмотреть трафик каждого
приложения за сутки, неделю или 30 дней, включая время до установки NetWatcher.
Это экспериментальная функция, которая использует учёт самой Windows.

В настройках можно включить уведомления Windows о программе, впервые замеченной в сети,
или её первом обращении к серверу в стране или сети (AS). NetWatcher сравнивает только
сохранённые наблюдения. Первые сутки после установки он запоминает обычные обращения.
Последовательные события объединяются в одно уведомление не чаще раза в 30 секунд.
Для браузеров учитывается только первое появление в наблюдениях.

### Следить за связью

Вкладка «Связь» открывается по умолчанию. Она помогает наблюдать за Telegram, играми и звонками,
NetWatcher использует сетевые события Windows и не читает содержимое трафика.
Для этого нужны права администратора. Без них программа сообщает, что наблюдение недоступно.

- **«нет ответа N с»** — программа отправляет данные, а сервер молчит больше 5 секунд.
  Для UDP статус появляется, только если сервер отвечал раньше. Для TCP нужны повторные отправки:
  обычная загрузка, где в ответ идут только подтверждения, не вызывает тревогу. Отсчёт начинается
  с первого пакета без ответа; долгий простой программы сам по себе не считается обрывом.
- Если молчит один второстепенный сервер, показано «не отвечает 1 из N серверов».
  Статус «без связи» относится к основному серверу программы.
- **Потери** измеряются проверочными пакетами до сервера раз в 5 секунд. Если сервер не отвечает
  на пинг, потери не измерены: показано «—». Отдельная пометка «повторы TCP» указывает
  на повторные отправки — признак возможных потерь, а не их точную долю.
- **Задержка и разброс** измеряются по пингу. Если ответов нет, показано «нет пинга»;
  само по себе это не ошибка. Для TCP задержку можно получить из соединения программы:
  Windows измеряет время отклика через расширенную статистику TCP. Такой замер отмечен «(TCP)»
  и помогает с серверами без пинга, например в играх и мессенджерах.

На вкладке есть график задержки, потерь и обрывов, таблица серверов с меню строк,
«Почему так решили» и события: «перестал отвечать», «восстановилась», «простой N с».

График по умолчанию — узкая полоса; кнопка «Развернуть» показывает его со шкалами.
При наведении видно время, задержку и потери в этой точке.

Под заголовками таблицы серверов — фильтр для каждого столбца: часть домена, IP или владельца;
по домену или по IP; TCP или UDP; состояние; задержка и разброс (границы — как в оценке
Cloudflare AIM: 20, 50, 100 мс и 10, 20 мс); есть ли потери; когда был ответ; был ли обмен за минуту.
Фильтр — это текст со стрелкой; включённый выделен цветом. Фильтры столбцов сужают только эту таблицу
(и карточки «Все программы») — список программ и таблица адресов от них не меняются.
Быстрые фильтры над вкладками выставляют фильтры столбцов: «TCP» и «UDP» — протокол, «С доменом»
и «Без домена» — способ обращения, «Проблемные» — состояние. Остальные («Трекеры», «Только новые»…)
сужают список серверов так же, как таблицу; над таблицей это написано. «Сбросить фильтры» сбрасывает
только столбцы.

«По IP» значит, что домен для адреса неизвестен. Обычно программа обратилась сразу по IP, но домен
не виден и тогда, когда программа сама спрашивает DNS (DNS через HTTPS) или узнала адрес до запуска NetWatcher.

Щелчок по серверу показывает его сведения в панели внизу, как у строки таблицы адресов.
Кнопки «домен» и «IP» появляются в строке под курсором и копируют одним щелчком; IP — без порта.
«Все домены» и «Все IP» копируют показанные серверы по одному в строке. `Ctrl+C` копирует строку,
`Ctrl+Shift+C` — только IP. В меню по правой кнопке остались действия, которых нет в строке и в панели:
«Копировать IP:порт», «Найти в «Все адреса»», «Заблокировать…» или «Снять блокировку…»,
для TCP — «Разорвать соединение…».
Когда ответы пропадают, NetWatcher сам проверяет путь и показывает, после какого узла
ответы не получены. Это не доказывает обрыв пути.

У «Все программы» — карточки и общий вывод, например «1 программа без связи, другие программы
получают ответы». Значок статуса есть и слева у каждой программы; пояснение — в подсказке.
Кнопкой у программы можно включить уведомления Windows о пропаже и возвращении связи
для неё или сразу для всех. История связи хранится в памяти за последний час работы.

### Оценить качество подключения

Вверху вкладки «Связь» показаны задержка, разброс и потери до роутера и внешнего адреса.
Проверочные пакеты отправляются раз в 2 секунды. «До роутера» — роутер физического подключения
по кабелю или Wi-Fi, даже с включённым VPN. Тогда второй замер называется «До интернета через VPN»
и включает задержку VPN.

Замеры показывают, до какого адреса растёт задержка или не приходят ответы. Причину они
не устанавливают. Чтобы сравнить с Wi-Fi, повторите проверку по кабелю.

NetWatcher также измеряет рост задержки при загрузке линии — bufferbloat. Он использует ваш трафик
и не создаёт лишнюю нагрузку. Оценки «Игры», «Звонки» и «Видео» рассчитаны по методике Cloudflare AIM.
Кнопка «Проверить под нагрузкой…» запускает около 20 секунд скачивания и отправки на полной скорости
через серверы теста скорости Cloudflare. Вы увидите скорость в обе стороны и задержку в это время.
Условия измерений и расход трафика описаны в разделе «Ограничения».

### Проверить сайт или адрес

NetWatcher сам отмечает адреса, которые не отвечают на подключение, подключаются с повторами
или теряют пакеты: ⚠ / ✕. У программы есть счётчик проблем, в поиске — фильтр «Проблемные».
В «Журнале DNS» видны неудачные запросы: «DNS не нашёл домен», «DNS-сервер не ответил»,
«ответ-заглушка 0.0.0.0» — возможный признак блокировки через DNS.

Нажмите **«Проверить»** (`Ctrl+D`), чтобы проверить сайт или адрес по шагам и получить итог.
Методы взяты из практики сетевых инженеров и открытых методик; ссылки есть ниже.

- **DNS.** Сравниваются системный DNS и независимый DNS через HTTPS. Как в OONI Web Connectivity,
  ответы согласованы, если совпадают адреса или сети (AS). При разных адресах сертификат сайта
  всё ещё может пройти проверку. Само расхождение адресов не доказывает подмену.
- **Возможная подмена DNS.** Запрос `o-o.myaddr.l.google.com` отправляется прямо к 8.8.8.8
  по UDP и TCP. Ответ DNS из другой сети может указывать на подмену запросов к 8.8.8.8,
  но не доказывает её. Запрос `whoami.akamai.net` помогает узнать адрес выхода вашего DNS в интернет.
- **Подключение и TLS.** Проверяется сертификат; ошибка сама по себе не доказывает перехват.
  Если первый адрес сайта не подключается, например из-за неработающего IPv6, программа пробует
  другое семейство адресов, как браузер.
- **Фильтр по имени сайта (SNI).** По методике OONI ts-024 нейтральный сервер `example.org`
  проверяется сначала с именем сайта, затем с контрольным именем. Категории результата — как у OONI.
  Ошибка TLS от `example.org` с именем сайта не подтверждает фильтрацию на проверенном пути.
- **HTTP/3 (QUIC, UDP 443).** Проверяется, только если сайт объявляет HTTP/3; нужна Windows 11.
  Если ответ по UDP 443 не получен, возможна фильтрация; браузер может перейти на TCP.
- **Задержка, путь по узлам и размер пакетов (MTU).** Проверка пути устроена как MTR: 10 проб
  на каждый узел, потери, задержка и владелец каждого узла. Проверка MTU ищет «чёрную дыру» —
  ситуацию, когда крупные пакеты не проходят. Если сайт открывается, отсутствие ответа сервера
  на трассировку нормально и не считается тревогой.
- **VPN.** Метка «VPN» появляется, если адаптер маршрута — VPN/TUN или ответ приходит за 1–2 мс
  в один узел. Замеры описывают VPN, а не прямое подключение провайдера. Через VPN трасса обычно
  состоит из одного узла: туннель отвечает за весь путь. NetWatcher поясняет, что путь до сервера не виден.
- **UDP-службы**, например игры и звонки, проверяются как `udp://адрес:порт`: только путь до сервера,
  без вывода по TCP-порту, который не относится к службе.

Кнопка «Копировать отчёт» готовит текст, который можно отправить в чат.

### Ограничить или разорвать соединение

Меню строки → «Заблокировать…» позволяет заблокировать программу целиком, службу Windows,
адрес, сеть владельца или домен — для одной программы или всех. NetWatcher создаёт обычное
правило брандмауэра Windows для исходящих соединений с именем «NetWatcher: …».
Оно действует и после закрытия NetWatcher, его видно в `wf.msc`.

Перед созданием правила окно показывает команду и предупреждает о компонентах Windows
и общих адресах CDN. Новые адреса домена добавляются по ответам DNS. Кнопка «Блокировки»
вверху открывает список правил, «Снять все» удаляет их. У заблокированных строк есть метка
«заблокировано». Ограничения блокировки перечислены ниже.

Пункт «Разорвать соединение…» закрывает открытые TCP-соединения программы с адресом, как в TCPView.
Нужны IPv4 и права администратора. Программа может подключиться снова.

### Скопировать или выгрузить список

В таблицах можно выделять и копировать часть текста. Выбранная строка и строка под курсором
подсвечиваются. В колонке «Куда» у них есть кнопка копирования и меню «⋯»; то же меню открывает
правая кнопка мыши. `Ctrl+C` копирует строки для Excel, `Ctrl+Shift+C` — только IP,
двойной щелчок — IP. Внизу появляется подтверждение с кнопкой «Отменить».

Кнопка «Экспорт списка» (`Ctrl+E`) готовит IP, домены, подсети или сети владельцев.
Ползунок «Насколько укрупнять» меняет список от точных адресов до /16. Можно выбрать формат:
список по строкам, WireGuard/AmneziaWG (`AllowedIPs = …`), «Файрвол Windows» через запятую
или «С маской» для роутеров. Есть комментарии с доменами и предпросмотр.

### Настроить вид и обновить программу

В настройках выберите тему: «Как в Windows», «Светлая» или «Тёмная».
Стандартные элементы оформлены в стиле Windows 11. Подсказки при первом запуске объясняют,
что уже работает, что нужно сделать и как искать.

NetWatcher проверяет новую версию при запуске и раз в сутки. Установка начинается по кнопке;
ваши данные сохраняются. Перед установкой проверяется контрольная сумма SHA-256 архива.

## Как запустить

1. Скачайте `NetWatcher-win-x64.zip` из [последнего релиза](https://github.com/aeyota93-cloud/NetWatcher/releases/latest).
2. Распакуйте и запустите `NetWatcher.exe`. Устанавливать .NET не нужно.
3. Разрешите запуск с правами администратора, когда Windows их запросит. Без них не видно системных процессов,
   доменов и UDP-соединений.
4. Справочники сетей, стран и доменов обычно встроены в релиз и доступны сразу. Обновить их можно в настройках.
   База владельцев IP занимает около 7 МБ. Если она недоступна или в ней нет адреса,
   сведения о его владельце и сети не показаны.

Нужна Windows 10 версии 1809 или новее либо Windows 11, 64-битная.

### Предупреждение «Windows защитила ваш компьютер»

У файла нет цифровой подписи. Поэтому SmartScreen — фильтр Windows для скачанных программ —
может показать предупреждение. Если вы доверяете файлу, можете запустить NetWatcher одним из двух способов:

- в окне предупреждения нажмите **Подробнее → Выполнить в любом случае**;
- перед запуском нажмите правой кнопкой по `NetWatcher.exe` → **Свойства** → **Разблокировать** → ОК.
  Это снимает отметку о загрузке из интернета, но не отключает другие проверки безопасности Windows.

## Откуда берутся данные

| Что | Откуда |
|---|---|
| Соединения TCP и номер процесса | Таблица соединений Windows (то же, что `netstat -ano`), опрос раз в 2 секунды |
| Короткие соединения и UDP (в том числе QUIC/HTTP3) | События ядра Windows (ETW — встроенная трассировка событий) |
| Домены | События DNS-клиента Windows: «программа спросила имя — получила такие IP» |
| Службы в svchost | Диспетчер служб Windows |
| Владелец и сеть | Офлайн-база [iptoasn.com](https://iptoasn.com) |
| Страна сервера | Офлайн-база «IP to Country Lite»: [IP Geolocation by DB-IP](https://db-ip.com), лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Компания домена, трекеры | [DuckDuckGo Tracker Blocklists](https://github.com/duckduckgo/tracker-blocklists), © Duck Duck Go, Inc., лицензия [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) |
| Телеметрия Windows | [WindowsSpyBlocker](https://github.com/crazy-max/WindowsSpyBlocker) (MIT, список от 2022 г.) и адреса диагностических данных из документации Microsoft |
| Объём трафика | События TCP/IP ядра Windows (размер каждого отправленного и полученного пакета) |
| Задержка без пинга | Расширенная статистика TCP Windows (`GetPerTcpConnectionEStats`, поле SmoothedRtt) |
| История трафика Windows | API Windows `ConnectionProfile.GetAttributedNetworkUsageAsync` — те же данные, что «Использование данных» в Параметрах |
| Блокировка | Брандмауэр Windows, правила создаются командой `netsh advfirewall firewall` |
| Качество подключения | Пинг роутера и 1.1.1.1 (или 8.8.8.8) раз в 2 секунды; трафик в интернет — из событий ядра Windows |
| Оценки «Игры / Звонки / Видео» | Методика Cloudflare AIM, перенесена из [cloudflare/speedtest](https://github.com/cloudflare/speedtest) (MIT), см. [условия использования](../THIRD-PARTY-NOTICES.md) |
| Тест под нагрузкой | Только по кнопке: скачивание и отправка через `speed.cloudflare.com` (те же адреса, что у открытого теста Cloudflare); результаты никуда не отправляются |
| Подробности о сети | RDAP через [rdap.org](https://rdap.org), только по кнопке |
| Название и тип сети | [PeeringDB](https://www.peeringdb.com), только по кнопке, ответы запоминаются |
| Ошибки DNS, зависшие подключения, повторные отправки | События DNS-клиента и TCP/IP ядра Windows, таблица соединений |
| Проверка соединения | Только по кнопке: системный DNS, DNS через HTTPS (1.1.1.1 и 8.8.8.8 по адресу, без системного DNS), подключение, TLS, ping, трассировка |

Данные хранятся в `%LOCALAPPDATA%\NetWatcher`: журнал `log.db` (SQLite — база данных в одном файле),
список блокировок `blocks.json`, настройки `settings.json` и справочные базы — владельцы сетей,
страны и каталог доменов. Сборка релиза включает три базы, если их удалось скачать. Если базы нет, программа попробует загрузить её отдельно. Раз в неделю свежие копии появляются
в служебных релизах `asn-db`, `geo-db`, `catalog-db` этого репозитория.

NetWatcher обращается в интернет для фоновых проверок связи, проверки обновлений программы,
обновления баз и действий по вашей команде: «Подробно о сети (RDAP)», «Владелец (PeeringDB)»,
«Проверить» и тест под нагрузкой. Загрузка обновления программы начинается по кнопке.

Каталог доменов собирает `tools/build-catalog.py` из списков DuckDuckGo. На него распространяется
та же лицензия — CC BY-NC-SA 4.0: **только некоммерческое использование**.
Для продажи программы нужно убрать каталог или получить лицензию у DuckDuckGo.

## Ограничения

- **Наблюдение за связью** учитывает пакеты и не знает, должен ли UDP-сервер отвечать.
  Поэтому «нет ответа» по UDP появляется, только если ответы были раньше. Если их не было ни разу,
  показано «ответов нет». Пороги — 5 секунд без ответа, 20 % потерь пинга и 5 % повторных отправок TCP —
  не проверены на всех играх.

- **Как читать трассу.** Роутеры могут ограничивать ответы на трассировку.
  Потери на промежуточном узле, которые не продолжаются дальше, могут быть связаны с этим ограничением.
  Потери ответов с узла до конца пути могут указывать на проблему. Если ответы теряются только
  на последнем узле, ограничивать их может сам сервер.
- **Балансировка нагрузки** может смешивать несколько путей в одной трассе. Такие узлы отмечены «(+1)».
  Для устойчивой трассы (Paris traceroute) и трассы по TCP в Windows нужен драйвер захвата пакетов
  Npcap/WinDivert: начиная с XP SP2 Windows запрещает отправлять TCP через raw-сокеты.
- **Отметка «не отвечает» в списке** — предположение по повторным попыткам подключения (SYN)
  в Windows. Пороги могут отличаться на вашей системе.

- **Проверка пути** использует ICMP — служебный протокол ping и tracert. Многие узлы на него
  не отвечают. Отсутствие ответов после узла не доказывает обрыв пути. С включённым VPN
  проверка соединения и трасса идут через VPN.

- **Домен виден не всегда.** Браузер со своим «безопасным DNS» (DNS через HTTPS) запрашивает имена
  в обход Windows, поэтому NetWatcher их не видит. Для таких соединений показаны только IP
  и владелец сети. Отключить эту функцию можно в настройках браузера: Конфиденциальность → Безопасный DNS.
- Домены собираются с момента запуска NetWatcher. Если другая программа узнала адрес раньше
  и сохранила его в своём кэше, домен появится только после следующего запроса.
- **Блокировке нужен брандмауэр Windows.** Если он выключен или заменён сторонним, например
  брандмауэром антивируса, правила не действуют. Окно блокировки предупреждает об этом.
  Домен блокируется по адресам: новые добавляются через несколько секунд после ответа DNS,
  поэтому первое соединение может пройти. Программы со своим DNS через HTTPS могут обойти
  блокировку домена. Адреса CDN общие для многих сайтов — блокировка затронет и другие сайты.
- **Качество подключения.** Без отдельного теста замер «Под нагрузкой» использует ваш трафик:
  не меньше 2 Мбит/с на скачивание или 1 Мбит/с на отправку. Это наблюдаемая нагрузка, а не предел линии.
  Без прав администратора трафик не виден: панель пишет «нагрузка не видна без прав администратора».
  Оценки появляются, когда известен рост задержки под нагрузкой. Для «Видео» нужен тест со скоростью
  скачивания — так же, как в библиотеке Cloudflare. Роутеры иногда обрабатывают пинг (ICMP) последним,
  поэтому отдельные скачки задержки бывают и без проблем.
  Тест расходует до 250 МБ на скачивание и до 100 МБ на отправку, плюс данные, которые уже были
  «в полёте». На мобильном интернете это заметно. Публичных условий использования серверов теста
  Cloudflare сторонними программами нет; эти же серверы по умолчанию использует открытая библиотека Cloudflare.
- **Задержка по TCP-соединению** — только для TCP и с правами администратора; для UDP (многие игры, звонки)
  без пинга задержку не узнать.
- **История трафика Windows** — экспериментальная функция. В документации Microsoft для этого API
  указано право приложений из Магазина. Доступность данных для обычной программы зависит от системы.
  Если Windows не отдаст данные, окно покажет ошибку. Те же цифры можно посмотреть в Параметрах:
  Сеть и Интернет → Использование данных.
- **Пометки доменов** отражают оценку списков DuckDuckGo и WindowsSpyBlocker. У самостоятельных
  сервисов — соцсетей, поисковиков, оплаты — показана только компания, без пометки «трекер»,
  хотя DuckDuckGo блокирует их на чужих сайтах. Список WindowsSpyBlocker не обновлялся с 2022 года.
- **Страна** определяется по бесплатной базе DB-IP Lite с точностью до страны. Возможны ошибки,
  в том числе у адресов крупных облаков и мобильных операторов.
- **Один IP может обслуживать много сайтов**, например через CDN. NetWatcher показывает домены,
  которые запрашивала выбранная программа. Если таких нет, показаны последние известные.
