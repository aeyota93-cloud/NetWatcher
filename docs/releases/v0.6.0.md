# Блокировка соединений

NetWatcher помогает ограничить соединения через брандмауэр Windows. Перед созданием правила можно посмотреть, что оно затронет и к чему может привести блокировка.

- Через «Заблокировать…» можно запретить исходящие соединения программы, службы Windows, адреса, сети владельца или домена. Правила брандмауэра Windows действуют и после закрытия NetWatcher; снять их можно в окне «Блокировки».
- Перед блокировкой видны команда и предупреждения о компонентах Windows, общих адресах CDN и выключенном брандмауэре. Адреса домена добавляются по ответам DNS: первое соединение может пройти, а собственный DNS программы может обойти такую блокировку.
- В карточках появились около 100 описаний программ, служб и доменов: зачем они используют сеть и к чему может привести блокировка. Последствия зависят от выбранного правила.
- Для TCP-серверов без ответа на пинг задержка берётся из самого соединения программы. Нужны права администратора; для UDP этот способ не работает.
- Добавлена экспериментальная история трафика по данным Windows за сутки, неделю и 30 дней, включая время до установки NetWatcher. Доступность данных зависит от системы.
- Для запуска теперь нужна 64-битная Windows 10 версии 1809 или новее либо Windows 11.
