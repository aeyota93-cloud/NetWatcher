# Сведения о владельцах без первого скачивания

База владельцев IP теперь встроена в программу. После запуска можно сразу посмотреть, какой сети принадлежит адрес.

- База владельцев IP встроена в программу: сведения доступны без скачивания при первом запуске.
- Обновление базы сначала использует копию на GitHub, затем исходный источник iptoasn.com. Если скачать её не удалось, сообщение объяснит причину. В настройках появилась кнопка «Загрузить из файла…».
- Сводка «Связь» отдельно показывает неактивные программы. График строится по реальному трафику; редкие повторные отправки TCP больше не считаются потерями.
- Статус «не работает» появляется, только когда молчат все серверы программы.
- Номер версии виден в строке состояния и настройках.
