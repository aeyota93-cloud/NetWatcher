# Каталог доменов

Здесь хранятся справочные данные для NetWatcher. Если нужна сама программа, откройте [последний релиз](https://github.com/aeyota93-cloud/NetWatcher/releases/latest).

- Каталог помогает узнать компанию домена и увидеть пометки «трекер», «телеметрия» или «опасный». Пометки отражают оценку источников; отсутствие пометки не подтверждает безопасность.
- Каталог собран из [DuckDuckGo Tracker Blocklists](https://github.com/duckduckgo/tracker-blocklists) (CC BY-NC-SA 4.0, © Duck Duck Go, Inc.) и [WindowsSpyBlocker](https://github.com/crazy-max/WindowsSpyBlocker) (MIT, © CrazyMax). Список WindowsSpyBlocker не обновлялся с 2022 года.
- Файл каталога распространяется по лицензии [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/): только для некоммерческого использования.
- Копия пересобирается автоматически раз в неделю. Обновить каталог можно в настройках NetWatcher. Это справочные данные; программа находится в релизах с номером версии.
