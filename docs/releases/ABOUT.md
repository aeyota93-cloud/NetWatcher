# Описание проекта и выпуск версий

## Короткое описание для GitHub

Показывает, какие программы Windows используют сеть и с какими серверами связываются. Помогает проверить соединение, посмотреть трафик и сохранить адреса для VPN или брандмауэра.

## Как писать описания

- Начните с того, что изменилось для пользователя. Назовите действие или проблему, затем результат.
- Пишите спокойно и прямо: короткие предложения, знакомые слова, без рекламных обещаний и канцеляризмов.
- Оставляйте технические подробности, только если они помогают понять результат или принять решение.
- Различайте наблюдение и вывод. Отсутствие ответа не доказывает обрыв; страна из базы может быть определена с ошибкой.
- Если нужно действие пользователя, дайте шаги. Ограничения и известные ошибки укажите рядом с соответствующей функцией.
- Описывайте изменения именно этой версии. Новые исправления не приписывайте старому выпуску; добавляйте отдельное примечание со ссылкой на исправление.

## Как выпустить версию

1. Обновите номер в `Directory.Build.props`.
2. Подготовьте описание в `docs/releases/vX.Y.Z.md` и добавьте его в тот же коммит.
3. Запустите тесты. В Windows: `dotnet test NetWatcher.sln -c Release`.
4. Отправьте коммит и тег `vX.Y.Z` на GitHub. Другой способ — Actions → build → Run workflow, указав ту же версию и нужную ветку.
5. Дождитесь завершения сборки. Проверьте описание, архив `NetWatcher-win-x64.zip` и его контрольную сумму в разделе Releases.

Сборка берёт текст из файла описания. Для служебных релизов используются `asn-db.md`, `geo-db.md` и `catalog-db.md`; еженедельное обновление данных сохраняет эту подачу.
