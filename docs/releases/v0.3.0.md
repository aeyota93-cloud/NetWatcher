# Больше сведений о проблемах со связью

Проверка подробнее показывает путь до сервера и помогает заметить возможные ограничения соединения. Результаты отдельных проб не всегда устанавливают причину сбоя.

- Проверка пути до сервера теперь делает 10 проб на узел и показывает потери, среднюю, лучшую и худшую задержку. Результаты обновляются во время проверки; разные ответы на одном шаге отмечены как балансировка.
- Проверка фильтра по имени сайта использует нейтральный сервер example.org и контрольное имя по методике OONI.
- Добавлена проверка возможной подмены запросов к DNS 8.8.8.8 по UDP и TCP. Отдельный запрос помогает узнать, через какой адрес ваш DNS выходит в интернет.
- При сравнении ответов DNS учитывается сертификат сайта. Разные адреса сами по себе не доказывают подмену.
- Добавлена проверка HTTP/3 через QUIC, если сайт объявляет его поддержку. Для неё нужна Windows 11.
- Проверка размера пакетов помогает искать ограничения MTU и случаи, когда крупные пакеты остаются без ответа. Отсутствие ответа само по себе не устанавливает причину.
