# Проверка сайта или адреса

Если сайт не открывается, запустите проверку прямо в NetWatcher. Программа покажет результаты по шагам и подготовит отчёт, который можно отправить за помощью.

- Кнопка «Проверить» и сочетание `Ctrl+D` запускают проверку сайта или адреса: DNS, подключение, защита соединения, задержка и путь по узлам. Результат можно скопировать кнопкой «Копировать отчёт».
- Проблемные адреса получают отметки ⚠ и ✕, у программ появился счётчик проблем. Фильтр «Проблемные» помогает найти такие соединения.
- В «Журнале DNS» видны неудачные запросы и ответы-заглушки 0.0.0.0 — возможный признак блокировки через DNS.
- Владельцы сетей показаны привычными именами, например Microsoft. Полное название из реестра осталось в подсказке; по кнопке можно уточнить имя и тип сети в PeeringDB.
- Тему можно выбрать в меню: «Как в Windows», «Светлая» или «Тёмная».
