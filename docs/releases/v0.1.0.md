# Первый выпуск

NetWatcher показывает сетевые соединения программ Windows и сохраняет историю обращений. Можно найти нужные адреса и подготовить список для настройки сети.

- Смотрите, с какими IP-адресами и доменами связываются программы и службы Windows. Службы показаны по именам, в том числе внутри svchost.exe.
- Выбирайте период и находите соединения по программе, домену, адресу, порту, владельцу сети или подсети. Обращения сохраняются в журнале; срок хранения можно изменить в настройках.
- Во вкладках «По доменам», «Все адреса» и «Журнал DNS» можно посмотреть адреса по группам, отсортировать их и узнать, какие имена запрашивала программа.
- Копируйте адреса, домены и сети. «Экспорт списка» готовит списки для WireGuard, AmneziaWG, брандмауэра Windows и роутеров. Перед копированием виден результат.
- В карточке адреса есть сведения о сети и владельце, кнопки копирования и запрос данных регистратора по RDAP.
- Выбирайте светлую или тёмную тему. Подсказки при первом запуске помогут начать работу.
- Программа запускается в Windows без отдельной установки .NET. Для системных процессов, доменов и UDP нужны права администратора; домены из DNS через HTTPS не видны.
