# Обновление программы и сведения под таблицей

Сведения об адресе теперь находятся под таблицей, а размеры панелей можно менять. Добавлена проверка новых версий и уточнены сообщения о результатах диагностики.

- Добавлены проверка и установка обновлений из программы. Новая версия проверяется при запуске и раз в сутки, установка начинается по кнопке. Перед установкой проверяется контрольная сумма SHA-256; данные сохраняются, при ошибке замены программа пытается вернуть прежний файл.
- Сведения об адресе перенесены под таблицу. Ширину списка программ и высоту сведений можно менять; размеры запоминаются. В таблицах можно выделять и копировать часть текста, у серверов на вкладке «Связь» появилось меню строки.
- Проверка соединения точнее учитывает ошибки защиты и результаты проверки имени сайта. DNS через HTTPS работает без системного DNS; если первый адрес не подключается, проверяется адрес другого семейства — IPv4 или IPv6.
- UDP-службы проверяются отдельно, без вывода по TCP-порту. У результата через VPN появилась метка; работающий сайт больше не получает предупреждение только за отсутствие ответов на трассировку.
- Исправлены ложные долгие перерывы после простоя. Один второстепенный сервер без ответа больше не означает потерю связи всей программы; восстановление отмечается только после ответа сервера.
- Неизмеренные потери показаны как «—», повторные отправки TCP подписаны отдельно. Без прав администратора программа сообщает, что наблюдение за связью недоступно.
- Период «Сейчас» больше не наследует ошибки всего часа. Домены привязываются к своей программе, а очистка истории сбрасывает и DNS в памяти.
- Уведомления можно выключить для отдельной программы, даже если включены уведомления обо всех. Копирование домена из сведений больше не захватывает пояснение.
- Тема теперь выбирается в настройках. Копирование адресов, доменов и сетей собрано в «Экспорт списка» (`Ctrl+E`); повторяющиеся действия убраны.

**Если кнопка «Обновить» не реагирует:** ошибка исправлена в 0.8.2. Скачайте [последний релиз](https://github.com/aeyota93-cloud/NetWatcher/releases/latest), полностью закройте NetWatcher и замените `NetWatcher.exe` файлом из архива. Журнал, настройки и блокировки сохранятся.
