# Фильтры и быстрое копирование во вкладке «Связь»

В таблице серверов на вкладке «Связь» появились фильтры по столбцам. Домен и IP теперь копируются одной кнопкой, а сведения о сервере открываются по щелчку.

- **Фильтр для каждого столбца.** Под заголовками таблицы серверов можно выбрать: часть домена, IP или владельца; обращение по домену или по IP; TCP или UDP; состояние; задержку и разброс; есть ли потери; когда был ответ; был ли обмен за минуту. Включённый фильтр подсвечен. Над таблицей видно, сколько серверов показано, и есть «Сбросить фильтры».
- **Быстрые фильтры сверху работают и на «Связь».** «TCP» и «UDP» выставляют фильтр протокола, «С доменом» и «Без домена» — способ обращения, «Проблемные» — состояние. Выбор в столбце включает и выключает эти кнопки. Остальные фильтры, например «Трекеры» и «Только новые», сужают список серверов так же, как таблицу адресов. В «Все программы» при фильтре остаются программы с подходящими серверами.
- **Копирование в один щелчок.** В строке под курсором появляются кнопки «домен» и «IP». IP копируется без порта. «Все домены» и «Все IP» копируют показанные серверы по одному в строке. `Ctrl+C` копирует строку, `Ctrl+Shift+C` — только IP.
- **Сведения по щелчку.** Щелчок по серверу показывает в панели внизу IP, домены, сеть владельца, страну, трафик и кнопки проверки, PeeringDB и RDAP — как у строки таблицы адресов.
- **Меню без повторов.** Из меню по правой кнопке убраны действия, которые есть в строке и в панели внизу. Остались «Копировать IP:порт», «Найти в «Все адреса»», «Заблокировать…» или «Снять блокировку…» и для TCP — «Разорвать соединение…».
- **Узкий график.** «Задержка и потери» по умолчанию занимает узкую полосу. Кнопка «Развернуть» показывает график со шкалами; выбор запоминается. При наведении на график видно время, задержку и потери в этой точке.

«По IP» значит, что домен для адреса неизвестен. Обычно это обращение сразу по IP, но домен не виден и тогда, когда программа сама спрашивает DNS (DNS через HTTPS) или узнала адрес до запуска NetWatcher.

Границы фильтров задержки и разброса взяты из оценки Cloudflare AIM: 20, 50 и 100 мс для задержки, 10 и 20 мс для разброса.
