# База стран

Здесь хранятся справочные данные для NetWatcher. Если нужна сама программа, откройте [последний релиз](https://github.com/aeyota93-cloud/NetWatcher/releases/latest).

- База помогает показать страну сервера по IP. Это копия без изменений базы IP to Country Lite — [IP Geolocation by DB-IP](https://db-ip.com), лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Копия обновляется автоматически раз в неделю; сам источник выпускает базу раз в месяц. В NetWatcher нажмите «Обновить базу» в настройках.
- Страна может быть определена с ошибкой, в том числе у крупных облаков и мобильных операторов. Она может отличаться от страны регистрации сети.
- Это справочные данные. Саму программу скачивайте из [последнего релиза](https://github.com/aeyota93-cloud/NetWatcher/releases/latest).
