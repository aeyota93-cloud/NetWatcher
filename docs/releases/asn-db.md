# База владельцев IP

Здесь хранятся справочные данные для NetWatcher. Если нужна сама программа, откройте [последний релиз](https://github.com/aeyota93-cloud/NetWatcher/releases/latest).

- База помогает узнать владельца IP-адреса и его сеть. Здесь хранится копия данных [iptoasn.com](https://iptoasn.com), которую NetWatcher обновляет из настроек кнопкой «Обновить базу».
- Копия обновляется автоматически раз в неделю. Если адреса нет в базе, сведения о его владельце и сети не показаны.
- Это справочные данные. Саму программу скачивайте из [последнего релиза](https://github.com/aeyota93-cloud/NetWatcher/releases/latest).
