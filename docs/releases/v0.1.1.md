# Загрузка базы и тёмная тема

База владельцев адресов загружается правильно, тёмная тема применяет выбранные цвета, а строка поиска больше не меняет размеры во время работы.

- Исправлена загрузка базы владельцев IP: сжатая база теперь читается правильно. Если вместо неё скачалась веб-страница, программа сообщит об этом.
- Исправлена тёмная тема: выбранные цвета применяются к интерфейсу.
- Поле поиска стало шире, верхняя панель больше не меняет размеры каждую секунду. Полный статус записи можно прочитать в подсказке.
- Добавлен значок NetWatcher для файла программы, окна и панели задач.
