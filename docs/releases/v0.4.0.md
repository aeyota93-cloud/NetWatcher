# Связь с серверами программ

Новая вкладка «Связь» помогает следить за играми, звонками и мессенджерами: получать сведения о задержке и замечать перерывы в ответах серверов.

- Вкладка «Связь» показывает обмен с серверами каждой программы. Она открывается по умолчанию и помогает наблюдать за играми, звонками и Telegram без чтения содержимого трафика.
- Если программа продолжает отправлять данные, а ответы прекратились больше чем на 5 секунд, появляется статус «нет ответа». Для UDP это работает, только если сервер отвечал раньше; для TCP учитываются повторные отправки.
- Добавлены график задержки, потерь и перерывов в ответах, таблица серверов, пояснение «Почему так решили» и события прекращения и возвращения ответов. Сервер без ответа на пинг не считается потерявшим все пакеты.
- При прекращении ответов NetWatcher автоматически проверяет путь по узлам. Отсутствие ответов после узла не доказывает обрыв именно там.
- В «Все программы» есть общая сводка, а слева у программ — статус связи. Уведомления Windows о пропаже и возвращении ответов можно включить для выбранной программы или для всех.
- Для наблюдения за связью нужны права администратора.
